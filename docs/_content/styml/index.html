Open source, MIT licensed

YAML for .NET. The API you already know. The performance you expect.

Styml is System.Text.Json's code and API, carried over to YAML 1.2: YamlSerializer, Utf8YamlReader, YamlDocument, YamlNode and a source generator. Code written against System.Text.Json reads the same with Yaml in place of Json.

Get started Try it in the browser
$ dotnet add package Styml

Program.cs

var service = new Service("web", "nginx:1.27", [80, 443],
    new() { ["TIER"] = "front", ["REPLICAS"] = "3" });

string yaml = YamlSerializer.Serialize(service);

Output

Name: web
Image: nginx:1.27

- 80
- 443

  TIER: front
  REPLICAS: "3"  # quoted: a plain 3 is a number

Features

System.Text.Json's design, and everything YAML adds

  1. 01

    The same API

    Options, attributes, converters, naming policies, the contract model and the source generator, renamed from Json to Yaml.

    Coming from System.Text.Json
  2. 02

    YAML 1.2, all of it

    Every valid case of the yaml-test-suite is read with the expected events, every error case is rejected.

    Reading YAML
  3. 03

    Anchors and aliases

    Aliases are read everywhere, ReferenceHandler.Preserve writes anchors, and alias expansion is bounded.

    References
  4. 04

    Tags, safely

    Tag-based polymorphism and tag mappings are explicit allow-lists: a tag never loads a .NET type.

    Polymorphism and tags
  5. 05

    Styles you choose

    Block or flow collections, plain, quoted, literal or folded scalars, comments, and quotes only where YAML needs them.

    Scalar styles
  6. 06

    A DOM that round-trips

    YamlDocument and YamlNode keep styles, anchors and tags, so an edited document keeps its look.

    The DOM
  7. 07

    Trimming and Native AOT

    A source-generated YamlSerializerContext serializes without reflection, with the analyzers on.

    Source generation
  8. 08

    Fast, few allocations

    A UTF-8 reader and writer over spans, pooled buffers, and a document that allocates 72 bytes.

    Performance

Source generation

Declare the types once, serialize without reflection

A YamlSerializerContext is generated at build time with the contracts of your types and the options you set on it, the YAML ones included. It works trimmed and with Native AOT.

Source generation 
string yaml = YamlSerializer.Serialize(service, AppYamlContext.Default.Service);
Service back = YamlSerializer.Deserialize(yaml, AppYamlContext.Default.Service)!;

[YamlSerializable(typeof(Service))]
[YamlSourceGenerationOptions(
    PropertyNamingPolicy = YamlKnownNamingPolicy.CamelCase,
    IndentSequences = true)]
public partial class AppYamlContext : YamlSerializerContext;
